# 当日の進行表（開発者用）

依頼主に名簿を登録してもらう日の台本。所要 **30〜40分**（依頼主が操作するのは約10分）。
くわしい理由・設定は [本番用Google設定の手順.md](本番用Google設定の手順.md)。依頼主に渡すのは Claude Docs の「利用記録・請求書ツール ご利用の手引き」。

---

## A. 前日まで

- [ ] 依頼主のメールアドレスを受け取った
- [ ] Google Cloud（上の欄が **Attendance Invoice Production**）→「Google Auth Platform」→「対象」→「テストユーザー」に **依頼主のアドレスだけ** を追加した（自分のアドレスが残っていないこと）
- [ ] 依頼主に「パスワード」と「2段階認証のスマホ」を持ってきてもらうよう伝えた
- [ ] 「ご利用の手引き」の連絡先欄を埋めて、印刷（またはPDF）した
- [ ] 名簿ファイル `個人情報/会員登録用_利用者名簿_2026-11-27.json` があることを確認した
- [ ] 氏名が怪しい4名の名前をメモした（紙の名簿と見比べる用）
- [ ] PCの充電・インターネット（Wi‑Fi／テザリング）を確認した

## B. 依頼主が来る10分前

1. 設定を本番に切り替える（どちらか）
   - Claude Code に「**本番に切り替えて**」と頼む
   - 自分で：PowerShell でこのフォルダを開き `Copy-Item .env.local.本番 .env.local`
2. アプリを起動し直す：黒い画面を閉じて `起動.bat`。自動で開いた普段のブラウザのタブは**閉じる**。
3. Chrome のゲストウィンドウを開いて http://localhost:3000 を表示し、「Google でログイン」の画面で止めておく。
4. 普段のブラウザのほかのタブ（メールなど）は閉じておく（画面を見せるため）。

### 名簿の読み込み（13〜18分）
1. 「会員管理」→ 一番下「データのバックアップ」→「**読み込み**」。
2. `個人情報/会員登録用_利用者名簿_2026-11-27.json` を選ぶ →「置き換えます」で OK。
3. 会員一覧に **34名（M0001〜M0034）** があることを一緒に見る。
4. 依頼主の Google ドライブ（ゲストウィンドウで drive.google.com）に「**利用記録・請求書データ**」ができていることを見せる。
   - **このスプレッドシートの URL を控える**（公開後に使う）。
   - 「このファイルは見るだけ、削除しないでください」と伝える。

## D. 使い方の説明（18〜35分）

実際に触ってもらう。⚠ **保存した出欠は消す機能がなく、そのまま請求に入る**ので、練習では「保存」を押さない。

1. **出欠**：
   - その日が利用日で、誰が来たか依頼主がわかる → **本当の出欠**を入れて「保存」まで（そのまま本番の記録になる）。
   - わからない／利用日でない → 「午前を全員利用」→ 1人「欠席」まで押して、**保存せずに**別の画面へ移る →「保存していない変更があります」の確認で破棄。「最後は画面下の『保存』を押します」と口で説明する。
   - 間違えて保存した場合：その日を開き、ボタンをもう一度押して全員「未確認」に戻して保存する（請求には入らないが、集計画面に注意が出る）。
2. **会員管理**：2割・3割の方が分かれば、1人だけ一緒に負担割合を直す（「編集」→「負担割合の変更」→ 何月分から）。
3. **集計・請求書**：今月を開き、請求書を1枚表示 →「印刷・PDF保存」の画面まで（印刷はしなくてよい）。
4. 「再接続」が出たら押せばよいことを伝える。

## E. 確認・修正のお願い（35〜40分）

- 負担割合（今は全員1割）、氏名4名、利用曜日・時間帯、利用開始日（全員 2026-11-01）を、手引きのチェック表で確認してもらう。
- 当日できなかった分は、後日ご自身で直してもらってよい（ただし公開前は依頼主のPCからは使えないので、**次回に一緒に**か、公開後に）。
- 今後の予定：請求書ひな形の受け取り → 書式を反映 → 公開 → 事業所のPCで初回のつなぎ込み。ひな形をもらえる時期を聞く。

## F. 終わったら（依頼主が帰る前に）

- [ ] ゲストウィンドウを閉じる（依頼主のログイン情報が消える）
- [ ] 設定を開発用に戻す：Claude Code に「**開発用に戻して**」と頼む（または `Copy-Item .env.local.開発用 .env.local`）→ 黒い画面を閉じて `起動.bat`
- [ ] 控えたスプレッドシートの URL を `個人情報/` フォルダに保存する（Git に入らない場所）
- [ ] 名簿ファイルを開発者のPCに残すか消すか、依頼主に決めてもらう
- [ ] 次回の日程（公開後のつなぎ込み）の目安を伝える

## 困ったとき

| 症状 | 対処 |
|---|---|
| 「アクセスをブロック：〜はテスト中です」 | テストユーザーに依頼主のアドレスが入っているか（A）。打ち間違いもよくある |
| 「redirect_uri_mismatch」「origin が許可されていません」 | 住所が `http://localhost:3000` になっているか（3001 だと不可）。黒い画面に出ている番号を確認し、ほかの黒い画面を閉じて起動し直す |
| ログイン後、何も作らずに古いスプレッドシートを開こうとする | ゲストウィンドウではなく普段のブラウザで開いている。ゲストウィンドウで開き直す |
| 2段階認証のスマホがない | 「別の方法を試す」でSMSや予備コード。無理なら日を改める（無理に進めない） |
| 名簿を読み込んだら人数が違う | 選んだファイルが違う。もう一度「読み込み」で正しいファイルを選べば全部置き換わる |
| ネットがつながらない | スマホのテザリングを使う |
