# 利用記録・請求書アプリ（試作版）

通所サービスの事業所で、**出欠の記録 → 月の集計 → 利用者ごとの請求書** までを1つのWebアプリで行うための試作版です。
紙からの転記をなくし、職員が少ない操作で出欠を入力できることを目的にしています。

> **これは試作版です**
> - 入っているデータは**すべて架空**です（会員30名・事業所名「ひだまりデイサービス（デモ）」）。**実際の利用者情報は入力しないでください。**
> - データの保存先は、設定で「このブラウザ（デモ用）」と「Googleスプレッドシート（本番用）」を切り替えられます。

---

## ⚠ データの保存場所について（必ずお読みください）

保存先は `.env.local` の `NEXT_PUBLIC_DATA_BACKEND` で選びます。

| 設定 | 保存先 | 用途 |
|---|---|---|
| `local`（または未設定） | このブラウザの中（localStorage） | デモ・試作。架空データが最初から入る |
| `sheets` | ログインした Google アカウントの Google ドライブにあるスプレッドシート | 本番用 |

### `sheets`（Googleスプレッドシート）のとき
- アプリを開くと「Google でログイン」の画面が出ます。初めてのPCでは「データ用のスプレッドシート」を**新しく作る**か、前に作ったものを**URLで開き**ます。
- スプレッドシートには「情報・会員・利用曜日・負担割合・出欠」のシートができます。**見るだけ**にしてください（手で編集しようとすると警告が出ます）。間違えて変えたときは、スプレッドシートの「ファイル」→「変更履歴」で戻せます。
- 保存のたびに、変わった部分だけを書き込みます。別のタブで更新されていた場合は、上書きせずに止めて再読み込みを案内します。
- Google の許可は約1時間で切れます。切れたら画面上の「再接続」を押します（入力中の内容は消えません）。
- このPCのブラウザに残るのは、スプレッドシートの場所（ID）だけです。
- 試作版のデータを移すときは、`local` の状態で「会員管理」→「データのバックアップ」→「書き出し」をしてから `sheets` に切り替え、「読み込み」で入れます。

### `local`（このブラウザ）のとき

- **別の端末・別のブラウザとはデータが共有されません。**（例：受付のパソコンで入力した記録は、タブレットからは見えません。同じパソコンでも Edge と Chrome では別々です）
- **ブラウザの閲覧履歴・サイトデータを消すと、記録が消える可能性があります。** シークレット（InPrivate）ウィンドウでは、閉じると消えます。
- 念のため、「会員管理」画面の一番下にある **「データのバックアップ」→「書き出し」** で、ファイルに保存できます（「読み込み」で戻せます）。

本番では `sheets` を使います（[docs/Google連携の準備.md](docs/Google連携の準備.md)）。

## 1. Windowsでの起動方法

### はじめに1回だけ：Node.js を入れる
1. https://nodejs.org/ja を開き、**「LTS」**と書かれたボタンからインストーラーをダウンロードします。
2. ダウンロードしたファイルを開き、「次へ」を押して最後まで進めます（設定は変更不要）。
3. 確認：スタートメニューで「ターミナル」（または「コマンドプロンプト」）を開き、`node -v` と入力して Enter。`v22.○.○` のように表示されればOKです。

### 毎回の起動
1. このフォルダ（`請求書自動作成ツール`）を開きます。
2. **`起動.bat` をダブルクリック**します。
   - 黒い画面が開きます。初回だけ準備（`npm install`）に数分かかります。
   - 準備ができると、ブラウザで **http://localhost:3000** が自動で開きます。
   - 開かない場合は、ブラウザのアドレス欄に `http://localhost:3000` と入力してください。
3. **終了するとき**は、黒い画面を閉じます（または黒い画面で `Ctrl + C`）。

> 「WindowsによってPCが保護されました」と出た場合は、「詳細情報」→「実行」を押してください（このフォルダの中のファイルを起動するだけです）。

### ターミナルから起動する場合
```bash
cd "請求書自動作成ツール"
npm install      # 初回だけ
npm run dev
```

### タブレット・スマホで見るには
パソコンと同じWi‑Fiにつなぎ、黒い画面に表示される `Network: http://192.168.x.x:3000` を開きます。
（※ 試作版では、タブレット側のデータはタブレットのブラウザに**別に**保存されます）

### その他のコマンド
| コマンド | 内容 |
|---|---|
| `npm run check` | 計算・ルールの自動チェック（曜日ごとの予定者、全員利用、振替、修正、曜日変更、集計、退会、負担割合、CSV・スプレッドシート出力、スプレッドシート保存の変換など 97項目） |
| `npm run typecheck` | プログラムの型チェック |
| `npm run build` | 本番用の作成（エラーがないかの確認） |

## 2. 画面と使い方

### ① 出欠を記録（最初に開く画面）
- 開くと**今日の日付**と、**その曜日に利用予定の会員**が表示されます。日付欄を押すと別の日を選べます。
- 各会員の「**利用**」「**欠席**」を押します。何も押していない方は「**未確認**」です（欠席扱いにはなりません）。
  - 選択中のボタンには「✓」が付きます。もう一度押すと「未確認」に戻ります。
- **全員利用**：表示中の全員を「利用」にします。その後、来なかった方だけ「欠席」を押します。
  - すでに「欠席」の方がいるときは、その方も利用に変えるか確認が出ます。
- **振替・追加**：右上の欄から会員を選んで「追加」。その日だけ一覧に入ります（追加しただけでは「未確認」）。
- 最後に、画面下の **「保存」** を押します。保存前は「● 未保存の変更があります」、保存後は「保存済み（時刻）」と表示されます。
  - 保存しないまま日付や画面を変えようとすると、確認が出ます。
- 過去の日付を選ぶと、保存済みの記録が表示され、修正して再保存できます。

### ② 月の集計・請求書
- 「◀ 前の月」「次の月 ▶」で年月を切り替えます。
- 会員ごとに **負担割合・利用日・利用回数・単価・金額（回数 × 単価）** を表示します。数えるのは「利用」だけです（欠席・未確認は含みません）。
  - 単価は、その方のその月の**介護保険の負担割合**で決まります（1割 358円／2割 716円／3割 1,074円）。
- 出欠を保存していない日や、未確認のままの記録があると、上に注意が表示されます。
- 「**請求書**」：その方1名分。「**全員分の請求書**」：その月に1回以上利用した全員分。
- 請求書画面の「**印刷・PDF保存**」で印刷画面が開きます（1人1ページ）。PDFにするときは、プリンターで「PDFに保存」（Edge/Chrome）を選びます。
  - きれいに印刷するには、印刷画面の「詳細設定」で **余白：なし** を選び、「ヘッダーとフッター」のチェックを外してください。
- 画面下の「**出欠表**」：縦に会員、横に日付を並べ、利用した日に「○」を付けた表です。横にスクロールしても氏名の列は固定されたままです。
- 「**Googleスプレッドシートに保存**」：出欠表を、あなたの Google ドライブ（マイドライブ）に新しいスプレッドシートとして作ります（ファイル名：`出欠表_2026年11月（事業所名）`）。
  - 中身：1行目に表題、2行目に見出し。氏名・会員番号・各日の○・利用回数・負担割合・単価・金額、最後の行に合計（日ごとの利用人数など）。
  - **氏名・会員番号の列と、表題・見出しの行が固定**されています（横・下にスクロールしても見えたまま）。
  - 初めて押したときは Google のログインと「許可」の画面が出ます。許可するのは「このアプリが作ったファイルだけ」の読み書きで、ドライブのほかのファイルは見えません。
  - 押すたびに新しいスプレッドシートが1つできます（前に作ったものは上書きしません）。
  - 使うには最初に1回、「4. Google スプレッドシート連携の設定」が必要です。
- 「**CSVで保存**」：同じ表を CSV ファイルで保存します（ほかのソフトに取り込む用。ブラウザの「ダウンロード」フォルダに入ります）。CSV は列の固定などの見た目を保存できません。

### ③ 会員管理
- 「＋ 新しく登録」：氏名・ふりがな（並び順用・任意）・利用曜日・**介護保険の負担割合（1〜3割、最初は1割）**・利用開始日。会員ID（M0001 など）は自動で付きます（同姓同名でも区別できます。デモの「佐藤 花子」さん2名が例です）。
- 「編集」：氏名の変更／**利用曜日の変更（この日から変更）**／**負担割合の変更（何月分から変更）**／退会・利用中に戻す。
  - 負担割合は「何月分から」を指定します。それより前の月の請求額は変わりません（例：8月分から2割に変わった方は、7月分までは1割のまま）。
  - 曜日変更は「いつから」を指定します。過去の予定・保存済みの記録は変わりません。
  - 退会日からは、出欠の予定一覧・追加候補に出なくなります。それまでの記録・請求データは残ります。
- 一番下の「データのバックアップ」：書き出し／読み込み／デモデータに戻す。

### デモデータの内容（架空）
- 会員30名（週1〜5回）。先々月1日〜昨日の出欠記録（約1割が欠席）。
- 西田 静子さん：今月1日から「月」→「火・木」に曜日変更した例
- 前田 隆さん：先月16日に退会した例（先月前半の請求は残っています）
- 木村 清さん：先月、土曜日に振替で利用した例
- 負担割合：上野 健二さん・鈴木 幸子さんは2割、久保 文子さんは3割、ほかの方は1割
- 高橋 節子さん：今月分から 1割 → 2割 に変わった例（先月までの請求は1割のまま）
- 今月最初の記録日に「未確認」のまま保存された記録が1件あります（集計画面の注意表示の例）

## 3. 単価・事業所名の変え方
`src/config.ts` だけを直します。

```ts
export const UNIT_PRICES = [
  { from: "2000-01", prices: { 1: 358, 2: 716, 3: 1074 } },  // 1割・2割・3割の単価
  // { from: "2027-04", prices: { 1: 400, 2: 800, 3: 1200 } },  ← 2027年4月分から変える場合は行を追加
];
```
単価は「何月分から」で管理しているため、変更しても過去の月の請求額は変わりません。
会員ごとの負担割合は、画面の「会員管理」→「編集」で変更します。

## 4. Google スプレッドシート連携の設定（最初に1回）
1. https://console.cloud.google.com/ で、新しいプロジェクトを作ります（例：「利用記録・請求書」）。
2. 「API とサービス」→「ライブラリ」で **Google Sheets API** を「有効にする」。
3. 「Google Auth Platform」（OAuth 同意画面）を設定します：アプリ名、サポートメール、対象は「外部」、**テストユーザーに自分の Gmail を追加**。
4. 「クライアント」→「クライアントを作成」→ 種類は **ウェブ アプリケーション**、「承認済みの JavaScript 生成元」に **`http://localhost:3000`** を追加して作成。
5. 表示された **クライアントID**（`〜.apps.googleusercontent.com`）を、このフォルダの `.env.local` に書きます（`.env.example` を参照）。
   ```
   NEXT_PUBLIC_GOOGLE_CLIENT_ID=〜.apps.googleusercontent.com
   NEXT_PUBLIC_DATA_BACKEND=sheets   ← データもスプレッドシートに保存するとき
   ```
6. アプリを起動し直します（黒い画面を閉じて、`起動.bat` をもう一度）。

- クライアントIDは秘密の鍵ではありません（ブラウザに渡る値です）。秘密の鍵（クライアントシークレット）は使いません。
- `http://localhost:3000` で開いたときだけ使えます。タブレットなど別の住所（`http://192.168.x.x:3000`）から使う場合は、その住所も手順4に追加が必要です（Google の決まりで、http の場合は使えないことがあります）。

## 5. プログラムの構成（後から連携を追加しやすくするため）

```
src/
  config.ts                 単価・事業所名など（設定はここだけ）
  lib/                      画面にも保存先にも依存しない「ルール」
    types.ts                データの形（会員・1日分の出欠記録）
    members.ts              会員の登録・曜日変更・退会、その日の予定者の判定
    attendance.ts           出欠一覧の作成、全員利用、保存内容の作成
    billing.ts              月の集計、単価（負担割合ごと）×回数
    attendanceSheet.ts      出欠表（縦＝会員・横＝日付・○）と CSV への変換
    googleSheets.ts         出欠表を Google スプレッドシートにするための依頼内容（列の固定・列幅など）
    demoData.ts             架空データ
  services/
    repository.ts           保存先の「窓口」（画面はここだけを使う）
    localRepository.ts      デモ用の保存先（ブラウザ内）
    sheetsRepository.ts     本番の保存先（Googleスプレッドシート。変わった部分だけ書き込む）
    googleAuth.ts           Google へのログイン（通行証の受け取り）と通信
    googleSheetsExport.ts   出欠表を新しいスプレッドシートに書き出す
  components/GoogleGate.tsx ログイン・初回設定の画面（sheets のとき）
  lib/sheetsFormat.ts       会員・出欠とスプレッドシートの行の変換
  app/                      画面（/ 出欠、/summary 集計、/invoices 請求書、/members 会員）
scripts/check-logic.mts     自動チェック
```

- 画面は `getRepository()` が返す「窓口」だけを通してデータを読み書きします。Googleスプレッドシートに切り替えるときは、同じ関数を持つ `sheetsRepository` を作って差し替えます（画面の修正はほぼ不要）。
- 1日分の出欠は「その日に表示されていた全員の状態」をそのまま保存します。会員の曜日を後で変えても、保存済みの記録は書き換わりません。
