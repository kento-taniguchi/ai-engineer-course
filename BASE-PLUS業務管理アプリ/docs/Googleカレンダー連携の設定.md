# Googleカレンダー連携の設定手順（初心者向け）

このアプリからGoogleカレンダーを読み書きするには、Google側で「このアプリがあなたのカレンダーを使ってよい」ことを登録する必要があります。
最初に1回だけ行えば、あとはアプリの「Googleに接続」ボタンで使えます。所要時間の目安は15〜20分です。

> **大切なこと**
> - 使うのは **「OAuth クライアントID」だけ** です（例：`123456789012-abc...apps.googleusercontent.com`）。公開される識別子で、パスワードではありません。
> - 作成時に **「クライアントシークレット」** も表示されることがありますが、このアプリでは **使いません**。どこにも貼り付けず、チャットにも送らないでください。
> - パスワードやAPIキーをチャットに貼る必要はありません。
> - **費用**：Google Calendar API は無料で使えます。請求先アカウント（クレジットカード）の登録は不要です。途中で「無料トライアルを開始」などの案内が出ても、このアプリのためには不要なので進めなくて大丈夫です。
> - Googleの画面の名前や配置は変更されることがあります。下の名前と少し違う場合は、近い名前の項目を選んでください。

---

## ① Google Cloud を開く

1. パソコンのブラウザで **https://console.cloud.google.com/** を開きます。
2. **BASE-PLUSで使っているGoogleアカウント**（カレンダーを使っているアカウント）でログインします。
3. 初めての場合は利用規約の画面が出るので、内容を確認して同意します。

## ② プロジェクトを作る

1. 画面上部の「プロジェクトを選択」（またはプロジェクト名）を押し、**「新しいプロジェクト」** を押します。
2. プロジェクト名に **`BASE-PLUS task manager`** と入力し、「作成」を押します（プロジェクト名に漢字は使えません）。
3. 作成後、画面上部でそのプロジェクトが選ばれていることを確認します。

## ③ Google Calendar API を有効にする

1. 左上のメニュー（≡）→ **「APIとサービス」→「ライブラリ」** を開きます。
2. 検索欄に **`Google Calendar API`** と入力し、表示された「Google Calendar API」を開きます。
3. **「有効にする」** を押します。

## ④ 同意画面（アプリの名前など）を設定する

1. 左上のメニュー（≡）→ **「APIとサービス」→「OAuth 同意画面」**（または「Google Auth Platform」）を開きます。
2. 「開始」などのボタンがあれば押し、次のように入力します。
   - アプリ名：`BASE-PLUS業務管理`
   - ユーザーサポートメール：自分のメールアドレス
   - 対象（ユーザーの種類）：**外部**
   - 連絡先メールアドレス：自分のメールアドレス
3. **公開ステータスは「テスト」のまま** にします（「アプリを公開」は押さないでください）。
4. **「対象」（または「テストユーザー」）** の画面で **「ユーザーを追加」** を押し、①でログインしたGmailアドレスを追加して保存します。
   - テスト中のアプリは、ここに追加したアカウントしか使えません（他人は使えないので安全です）。
5. （任意）「データアクセス」（スコープ）の画面で次の3つを追加しておくと、後で確認しやすくなります。
   - `.../auth/calendar.calendarlist.readonly`（カレンダーの一覧を見る）
   - `.../auth/calendar.events.readonly`（予定を見る）
   - `.../auth/calendar.events.owned`（自分のカレンダーの予定を作成・変更）

## ⑤ OAuth クライアントID を作る

1. 左上のメニュー（≡）→ **「APIとサービス」→「認証情報」**（または Google Auth Platform の「クライアント」）を開きます。
2. **「認証情報を作成」→「OAuth クライアント ID」**（または「クライアントを作成」）を押します。
3. アプリケーションの種類：**「ウェブ アプリケーション」**
4. 名前：`BASE-PLUS業務管理（パソコン）`
5. **「承認済みの JavaScript 生成元」** に **`http://localhost:3000`** を追加します。
   - 「承認済みのリダイレクト URI」は **空のままで大丈夫** です。
6. 「作成」を押すと、**クライアントID** が表示されます。
   - クライアントIDの右のコピーボタンでコピーします。
   - **クライアントシークレットは使いません。** 何もせず閉じてください。

## ⑥ アプリにクライアントIDを登録する（どちらか一方）

### 方法A（おすすめ）：設定ファイルに保存する
1. アプリのフォルダ（`BASE-PLUS業務管理アプリ`）に、`.env.local` という名前のファイルを新しく作ります。
2. 中身を次の1行にします（`=` の右側に⑤でコピーしたクライアントIDを貼る）。
   ```
   NEXT_PUBLIC_GOOGLE_CLIENT_ID=ここにクライアントID
   ```
3. ターミナルで動いている `npm run dev` を `Ctrl + C` で止め、もう一度 `npm run dev` を実行します。
   - `.env.local` はGitに保存されない設定になっています（`.gitignore` に含まれています）。

### 方法B：アプリの画面に入力する
1. アプリの左メニュー **「Google連携」** を開きます。
2. 「1. 初期設定」の欄にクライアントIDを貼り付けて「保存」を押します。
   - このブラウザの中にだけ保存されます。

## ⑦ アプリから接続する

1. アプリの **「Google連携」** 画面で **「Googleで連携する」** を押します。
2. Googleの画面が開いたら、アカウントを選びます。
3. **「このアプリは Google で確認されていません」** と表示されます（テスト中の自分専用アプリのため）。
   - 「詳細」→「BASE-PLUS業務管理（安全ではないページ）に移動」を押します。自分で作ったアプリなので問題ありません。
4. 権限の確認画面で、**「カレンダーの一覧を見る」「予定を見る」** にチェックが入っていることを確認して「続行」（許可）を押します。
5. アプリに戻り、状態が **「接続中」** になれば接続完了です。
   - ここまで終わる前は「接続中」とは表示されません。

## （おすすめ）試験用のカレンダーで確認する
実際の予定に触れずに確認するため、Googleカレンダーで **「BASE-PLUSテスト」** というカレンダーを新しく作り、架空の予定（例：`パーソナル 伊藤陽向`、明日 18:00〜19:00）を1件入れます。
アプリでは、読み込むカレンダーと作業予定の登録先の **両方を「BASE-PLUSテスト」だけ** にします。
アプリが変更・削除するのは、アプリ自身が登録した作業予定（予定名が「【BASE-PLUS作業】」で始まるもの）だけで、既存の予定は変更しません。

## ⑧ 使い始める

1. 「3. 使うカレンダー」で、読み込むカレンダーにチェックを入れます。
   - 作業予定を登録したい場合は「作業予定を登録するカレンダー」を選びます（「BASE-PLUS作業」用のカレンダーをGoogleカレンダーで作っておくのがおすすめです）。
2. **「予定を読み込む」** を押します。
3. 「4. 予定を選手・チームの予約に紐づける」で、BASE-PLUSの予約の予定に **「紐づける」** を押し、対象者と日時を確認して紐づけます。
4. 初めてアプリから作業予定を登録するときは、Googleの画面で **「自分のカレンダーの予定を作成・変更」** の許可を求められます。

## よくある表示と対処

| 表示 | 対処 |
|---|---|
| 再接続が必要 | 約1時間で接続が切れる仕組みです（安全のため保存していません）。「Googleに再接続」を押してください。ページを再読み込みしたときも同じです。 |
| Googleの画面を開けませんでした | ブラウザのポップアップブロックを解除してください。 |
| 「Google Calendar API」が有効になっていません | 手順③をもう一度確認してください。 |
| エラー「redirect_uri_mismatch」「origin_mismatch」 | 手順⑤の「承認済みの JavaScript 生成元」に `http://localhost:3000` が入っているか確認してください（末尾に `/` を付けない）。 |
| アクセスがブロックされました（テストユーザー） | 手順④-4のテストユーザーに、ログインしたアカウントが追加されているか確認してください。 |

## iPhoneで使う場合について
Googleの決まりで、`http://192.168.x.x:3000` のような **パソコンのアドレス（http）からはGoogleに接続できません**。
iPhoneから使うには、アプリを **https のアドレスで公開** する必要があります。2026-11-19 に Vercel で公開し、手順⑤の「承認済みの JavaScript 生成元」に公開先のアドレスを追加済みです（`docs/データ共有の設計.md` の「8. 公開（Vercel）の運用メモ」）。

## やめたいとき
- アプリの「Google連携」→「連携を解除」で、Google側の許可も取り消します。
- Googleアカウント側からは https://myaccount.google.com/permissions で「BASE-PLUS業務管理」のアクセスを削除できます。
- クライアントIDを誤って公開の場所に貼った場合でも、パスワードではないため直ちに危険はありませんが、気になる場合は手順⑤の画面でクライアントを削除し、作り直してください。
