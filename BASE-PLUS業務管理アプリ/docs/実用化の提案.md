# 実用化に向けた現状の整理と提案（第5版時点）

## 1. 現在の状態

| 項目 | 現状 |
|---|---|
| 技術 | Next.js 16 ＋ React 19 ＋ TypeScript。外部のUIライブラリ・データベースなし |
| 起動方法 | `npm install`（初回のみ）→ `npm run dev` → http://localhost:3000 |
| データの保存場所 | 予約・ToDo・選手・チーム・レポート・指導メモ・測定結果・SNS・セミナー・Google連携の設定と予定の控え：**ブラウザの localStorage**（キー `baseplus-demo-data-v1`、約5MBまで）／プチセミナーの画像・動画：**ブラウザの IndexedDB** |
| バックアップ | 設定画面の「データを書き出す（JSON）」でファイルに保存。第5版で「書き出したファイルから戻す」を追加（置き換える前に今のデータを同じブラウザ内に退避）。画像・動画はファイルに含まれない |
| データの形の更新 | `src/lib/migrate.ts` で古い形から自動で移行し、移行前のデータを `baseplus-backup-v◯` として退避 |
| Googleカレンダー | 第5版で実装（予定の読み込み・予約との紐づけ・ToDo作成・変更の反映・作業予定の登録）。Google Cloud での初期設定と接続が必要 |
| PCとiPhoneでのデータ共有 | **できない**（ブラウザごとに別々に保存されるため） |

### PCとiPhoneで同じデータを扱うために不足しているもの
1. **インターネット上のデータベース**（今はブラウザの中だけ）
2. **ログイン（本人確認）**（今は、そのブラウザを開ける人なら誰でも見られる）
3. **https で公開されたアプリ**（今はパソコンの中だけで動いている。Googleの接続も https が必要）
4. **画像・動画のクラウド保存先**
5. **自動バックアップ**
6. **アクセス制御**（谷口さん本人だけが見られる・書ける）

## 2. 実際の選手情報を扱うための提案

### おすすめの構成（案）
| 役割 | 候補 | 理由 |
|---|---|---|
| アプリの公開（https） | Vercel | Next.js を作った会社のサービスで、設定が簡単 |
| ログイン | Supabase Auth（Googleログイン） | Googleアカウントでログインでき、パスワード管理が不要。**谷口さんのメールアドレスだけを許可** する |
| データベース | Supabase（PostgreSQL） | 「行レベルセキュリティ（RLS）」で、ログインした本人以外は1件も読めない設定にできる |
| 画像・動画 | Supabase Storage（非公開バケット） | 公開URLを作らず、ログイン中に期限付きのURLでだけ表示 |
| バックアップ | Supabase の自動バックアップ＋定期的なJSON書き出し | 有料プランで毎日自動。無料プランでは手動の書き出しで補う |
| Googleカレンダー | 今の方式（ブラウザで接続）を継続、または次の段階でサーバー側の接続に変更 | サーバー側にすると「1時間ごとの再接続」が不要になる（秘密情報はサーバーの環境変数に保存） |

※ Firebase（Google）でも同様の構成が可能です。Googleカレンダーとの相性を重視する場合の候補です。

### 個人情報・未成年の記録を扱う前提での設計
- **誰でも見られる状態にしない**：すべての画面とデータにログインを必須にし、データベース側でも本人以外の読み書きを拒否（RLS）。画面だけで隠すことはしない
- **画像・動画は非公開**：公開リンクを作らない。共有が必要なときは期限付きリンク
- **必要な情報だけ保存**：住所・学校名など、指導に不要な情報は入れない。怪我の情報は特に慎重に
- **保護者の同意**：記録・写真・動画の保存と利用目的について、保護者の同意を得る（同意の有無を記録できる項目を追加予定）
- **退会・削除**：選手の記録を削除・書き出しできるようにする
- **通信は https のみ**、端末にはパスコード・生体認証を設定
- **アクセス記録**：誰がいつログインしたか確認できるようにする

### 費用の目安（2026年11月時点の公開情報をもとにした目安。契約前に必ず最新の料金を確認してください）
- Google Calendar API：無料
- Vercel：**無料プラン（Hobby）は個人の非商用向け**。事業で使う場合は有料プラン（月額 約20ドル〜）の検討が必要
- Supabase：無料プランあり（容量が小さい・しばらく使わないと一時停止する・自動バックアップなし）。実運用は有料プラン（月額 約25ドル〜）が安心
- 動画を多く保存すると容量に応じた費用が増えるため、動画は長さ・画質の上限を決める
- **費用が発生する契約・登録の前に、必ず内容を確認してから進めます**

### 移行の進め方（データを勝手にアップロードしない）
1. 保存先（サービス）を谷口さんと決める
2. 本人だけがログインできる空のデータベースを作り、アクセス制御を確認（架空データで試験）
3. 谷口さんが設定画面で「データを書き出す」→ 新しいアプリで「読み込み」（本人の操作で移す）
4. 画像・動画は、必要なものだけ本人が選んでアップロード
5. 実際の選手情報の入力は、同意の取得・アクセス制御の確認が終わってから
