# 営業先リスト

Googleマップ、Gビズインフォ、企業ホームページなどの公開情報をもとに、新規営業の候補企業を整理するツールです。初期の対象地域は福井県内です。

## 起動方法

```
cd 営業先リスト作成ツール/prospect-list
npm install
npm start
```

ブラウザで http://localhost:3100 を開きます。終了するときは、起動した画面で Ctrl + C を押します。

## 画面

- 営業先一覧：今日の候補、確認待ち、フォロー予定などを切り替え、絞り込み、CSV出力ができます
- 候補詳細：公式連絡先、確認できたこと（出典URL・確認日つき）、提案の仮説、商談で確認したいこと、営業履歴を確認し、営業結果を記録します
- 候補の追加・編集：事実と連絡先は出典URLがないと保存できません

## 候補データの取り込み

`seed` フォルダに、公開情報から調べた福井県内の候補企業のデータがあります。

- `seed/fukui-2026-11.json`：35社（公式連絡先を確認できた32社＋連絡先が未確認の3社）。2026年11月17日に確認

取り込むには、次のコマンドを実行します。

```
npm run import -- seed/fukui-2026-11.json
```

- 同じ企業がすでに登録されている場合は取り込みません。何度実行しても重複しません
- 営業履歴のない【見本】データは取り除きます
- アプリの起動中でも取り込めます（取り込み後に画面を再読み込み）

### データの出典

- 福井市「福井市の企業をご紹介します！」の企業紹介PDF（2026年度版）
- 福井県「ふくいSDGsパートナー取組事例集（令和4年度）」
- 各社の公式サイト（電話番号・問い合わせフォームは公式サイトで確認したものだけを登録）

優先度の点数と提案仮説は、公開情報からの仮評価です。先方には確認していません。

## データの保存場所

`prospect-list/data/prospects.json` に保存します。このフォルダは `.gitignore` に入っているため、GitHubには公開されません。

## 初期版で決めた方針

1. 候補は手入力か、公開情報を調べてまとめたデータの取り込みで登録する（自動収集は行わない）
2. 地域は福井県内の17市町から選ぶ
3. 今日の候補は、連絡先を確認できた未着手・対応日到来の候補から優先度順に最大30件
4. 優先度は、0〜5点で評価した項目だけの平均（「不明」は0点として数えない）
5. データはこのPC内に保存する
